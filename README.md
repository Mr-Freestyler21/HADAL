# HADAL
Explore the Hadal Zone, the deepest and most mysterious part of the ocean. Named for the underworld, it's a realm of eternal darkness, crushing pressure, and the strange, bioluminescent life that thrives in Earth's last true frontier.

Interactive Depth Meter: A UI element built with JavaScript that tracks the user's scroll depth in real-time, updating from 6,000m to 10,935m as they "descend."

Fluid Smooth Scrolling: Uses the Lenis library to create a high-performance, smooth-scrolling experience that feels premium and fluid.

Animated "Underwater" Background: A pure CSS, multi-layered particle animation that remains fixed, giving a 3D "parallax" effect as the content scrolls over it.

Responsive Design: The site is fully responsive, built using CSS Flexbox, Grid, and the Bootstrap grid system to adapt to all screen sizes, from mobile to desktop.

Bioluminescent Theme: A dark-mode design featuring CSS glow effects (text-shadow, box-shadow) to create an "underwater" bioluminescent feel.

TECHNOLOGIES USED
HTML5: Semantic HTML for structure and accessibility.

CSS3: Custom Properties (variables), Flexbox, CSS Grid, Keyframe Animations, and pseudo-elements.

JavaScript (ES6+): Used for DOM manipulation (updating the depth meter) and handling browser events (scroll and click).

Lenis: A modern library for smooth scrolling.

Bootstrap 5: Utilized for the responsive container and row/col grid in the "Explorers" section.
